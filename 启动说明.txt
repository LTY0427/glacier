===========================================
冰川数据查询与预测系统 - 运行说明
===========================================

【方案一：使用原有模板系统（无需Node.js）】

1. 直接运行后端：
   cd E:\AIcode\ruanzhu
   conda activate ruanzhu
   python app.py

2. 访问系统：
   打开浏览器访问：http://localhost:5000

3. 功能说明：
   - 左侧：数据查询模块（输入ID查询历史数据）
   - 右侧：预测分析模块（输入ID进行预测）
   - 地图功能：点击地图按钮查看冰川位置

===========================================

【方案二：使用Vue前端系统（需要Node.js）】

第一步：安装Node.js
- 下载地址：https://nodejs.org/
- 安装后重启命令行

第二步：安装前端依赖
   cd E:\AIcode\ruanzhu
   npm install

第三步：开发模式运行（两个终端）

终端1 - 前端开发服务器：
   npm run dev
   （访问 http://localhost:2450）

终端2 - 后端服务器：
   conda activate ruanzhu
   python app.py
   （API服务在 http://localhost:5000）

或者生产模式（一个终端）：
   npm run build
   python app.py
   （访问 http://localhost:5000）

===========================================

【推荐：先使用方案一测试功能】

如果Node.js未安装，可以直接运行：
   python app.py

然后访问 http://localhost:5000 使用原有界面
